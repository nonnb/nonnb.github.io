# Cloning Integration

Once integration with a Hosting Provider has been configured, SmartGit's Clone command will allow navigation to browse repositories available to you on the hosting provider.
You can then select the required repository, and clone it, without needing to copy the Clone URL from the hosting provider and paste it into SmartGit.

SmartGit will display your own (*user*) repositories, as well as repositories of your organization (*org*).
