# AI Commit Annotations

Is a flexible feature which instructs SmartGit to run custom AI actions, either interactively, or in the background

- Describe the contents of a diff, which can be the latest commit on a branch, or the diff between 2 commits
- Analyse a commit and provide indicators or descriptive metadata about quality, security, or other metrics associated with the code introduced in the commit.
