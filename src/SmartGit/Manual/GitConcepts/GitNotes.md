# Git Notes

An often overlooked feature in Git is `git notes` - 


As git notes are linked to an existing commit, rather than part of the commit, it means notes can be added and removed after the commit is created, and does not modify the commit history.




Example uses for git notes

- References to requirements (as an alternative to linking)
- Linking peer / code review comments to a commit
- Performing distributed code reviews without requiring additional persistence in a git hosting service such as GitHub or Bitbucket.
